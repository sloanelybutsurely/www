---
title: SingleFile
---

Website: [getsinglefile.com](https://www.getsinglefile.com/)

Browser extension that saves entire web pages as single web page. Includes all
resources (images, stylesheets, etc.) via datauri.

Great for making archive copies of things.

Integrates nicely with linkding[^1].

Also available as a [cli tool](https://github.com/gildas-lormeau/single-file-cli).


[^1]: [linkding.link - Archiving - Using the SingleFile Browser Extension](https://linkding.link/archiving/#using-the-singlefile-browser-extension)
